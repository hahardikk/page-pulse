# 🚀 PagePulse UI

React frontend for the PagePulse website auditing application.

---

## Features

- Clean Responsive UI
- Website Audit Form
- Displays Audit Results
- Error Handling
- Axios API Integration

---

## Tech Stack

- React
- Vite
- Axios
- CSS

---

## Installation

```bash
npm install
```

---

## Run

```bash
npm run dev
```

Runs on

```
http://localhost:5173
```

---

## Environment Variables

Create a `.env` file.

```
VITE_API_URL=http://localhost:8080/api/audit
```

Example

```
cp .env.example .env
```

---

## Build

```bash
npm run build
```
